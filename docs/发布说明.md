# WinLaunch v1.0.0 发布说明

Windows 10/11 上的 macOS 式桌面增强：**程序坞（Dock）+ 启动台（Launchpad）**。
免安装、免管理员、不联网；配置和缓存都写在自己的用户目录里，卸载可清干净。

## 系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 1903+ / Windows 11（32/64 位均可） |
| 运行时 | .NET Framework 4.8（Win10 1903 起系统自带） |
| 权限 | 普通用户即可，**不需要管理员**（个别提权应用启动时会由系统弹 UAC） |
| 磁盘 | 程序约 0.2 MB；图标缓存最多几十 MB |

## 下载哪个文件

| 文件 | 适合谁 | 说明 |
|---|---|---|
| `WinLaunch-1.0.0-setup.exe` | 大多数人 | 安装包：开始菜单 + 可选桌面快捷方式、卸载器（可一并清配置和缓存） |
| `WinLaunch-1.0.0-portable.zip` | 想免安装 / 放 U 盘 | 解压出 `WinLaunch.exe` 双击即用，不写注册表 |

安装包默认装到当前用户目录，**不会**申请管理员权限：

```
%LOCALAPPDATA%\Programs\WinLaunch
```

## 校验下载完整性

每个版本附 `SHA256SUMS.txt`，格式为 `哈希  文件名`。在 PowerShell 里：

```powershell
Get-FileHash .\WinLaunch-1.0.0-setup.exe -Algorithm SHA256
```

输出与 `SHA256SUMS.txt` 中对应行一致即可。

## 首次运行

1. 屏幕底部出现程序坞，托盘出现 WinLaunch 图标（可能在托盘折叠区里）。
2. 首次启动会自动扫描开始菜单和 Microsoft Store 应用，并把常用应用放进程序坞。
3. 快捷键：`Ctrl + Alt + L` 打开启动台，`Ctrl + Alt + D` 显示/隐藏程序坞。
4. 托盘右键 → 退出 WinLaunch。

数据和缓存位置：

```
%APPDATA%\WinLaunch\                  config.json / usage.json / logs
%LOCALAPPDATA%\WinLaunch\cache\icons  图标缓存（可随时删，会自动重建）
```

## 卸载

**安装包版**：设置 → 应用 → WinLaunch → 卸载（或开始菜单 →「卸载 WinLaunch」）。
卸载结束时会询问是否删除配置和缓存：

- 选「是」：删除 `%APPDATA%\WinLaunch`、`%LOCALAPPDATA%\WinLaunch`，并清掉开机自启项，**零残留**
- 选「否」：保留数据和设置，方便以后重装继续用

> 静默卸载（`/VERYSILENT`）**一律保留数据**，防止脚本误删。确实要连数据一起清掉时，显式加参数：
> `unins000.exe /VERYSILENT /DELETEUSERDATA=1`

**绿色版（zip）**：手动删 4 处即可彻底清干净：

```powershell
# 1) 程序本体（你解压到哪就删哪）
Remove-Item -Recurse -Force .\WinLaunch

# 2) 配置 / 使用记录 / 日志
Remove-Item -Recurse -Force "$env:APPDATA\WinLaunch"

# 3) 图标缓存
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\WinLaunch"

# 4) 如果开过「开机自启」，删掉注册表项（没有就忽略报错）
Remove-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name WinLaunch -ErrorAction SilentlyContinue
```

> 便携模式说明：如果 `%APPDATA%` 不可写（例如从只读或受限目录运行），程序会回退到
> `exe 同级 data\` 目录，托盘会有气泡提示。正常解压到普通目录不会触发。

## v1.0.0 包含

- 启动台：全屏覆盖、实时背景虚化、9×5 自适应网格、分页、中文/拼音搜索、键盘导航、拖拽到程序坞、常用行
- 程序坞：半透明圆角、悬停放大、运行指示点、固定/临时分组竖线、单击启动/切换/最小化（与任务栏一致）、拖拽排序、拖入钉住、拖出移除、自动隐藏、全屏抑制
- 图标：四级降级提取（IShellItemImageFactory 256 → Jumbo → 32 → 字母色块），磁盘缓存带版本号自动失效
- 系统集成：托盘菜单、全局热键、单实例、启动去重、开机自启、配置原子写入与备份回滚
- 健壮性：全局异常捕获、按天滚动日志、图标线程 STA 隔离

完整操作说明见 [使用说明](使用说明.md)。

## 已知限制

多显示器仅铺主屏、混合 DPI 未逐屏适配、部分 Microsoft Store 应用只有纯色磁贴图标、部分拖拽交互仅人工验证。
详见使用说明的「已知限制」一节。
